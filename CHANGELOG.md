# Changelog

## 2026.09.08.1

Real keys instead of a quiz show. On a real keyboard, mixed mode is now 3 presses out of 4. New "keys only" mode: no multiple choice at all — press the combo, tap the drawn keyboard when the OS steals it, or do the mouse gesture. Quiz answers are keyboard-driven (1–4, Enter, Backspace), AZERTY and numpad included. Ctrl+T / Ctrl+W / Ctrl+Tab are never asked as a real press: the browser refuses `preventDefault` and the tab would close. Cache `racc-v3`.

## 2026.08.26.1

Remove the age picker. Detect phone vs real keyboard. Playable on a phone (no `press` on touch). Kid-plain briefs and prompts. Cache `racc-v2`.

## 2026.08.25.1

First public GitHub Pages app: keyboard-shortcut quest for ages 10–15, FR/EN, self-hosted fonts, PWA, local progress, MIT.
